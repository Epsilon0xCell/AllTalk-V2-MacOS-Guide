AllTalk-V2-MacOS-Guide

Updated Guide to installing AllTalk v2 on macOS

FIG. 0 - Banner from this repo. Logo file: logo.png, also in the repo root.

What this is

I wrote this guide because I wanted AllTalk v2 running on my Mac and the steps needed to be in one place, in order. This repo is instructions only. It contains no code of its own.

The steps run in order. Each section assumes the ones before it are done, and the working directory matters. The environment is created inside the cloned repo, then the guide steps back out of it before the requirements are installed.

Read the scope note at the end before you start. The pinned versions are a dated snapshot, not a promise that they are still current.

The plates. Follow them in order.

PLATE 1

Homebrew and command line tools

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew unlink espeak
brew install espeak ffmpeg gcc git curl espeakng
xcode-select --install
PLATE 2

Clone AllTalk and create the environment folder

git clone -b alltalkbeta https://github.com/erew123/alltalk_tts
cd alltalk_tts
mkdir alltalk_environment
cd alltalk_environment

Note the spelling. The folder is alltalk_environment. An earlier version of this guide had a typo in that name in the wheel step, and I fixed it.

PLATE 3

Miniconda and the Python environment

curl -LO https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh
bash Miniconda3-latest-MacOSX-arm64.sh -b -p $PWD/conda
./conda/bin/conda create --no-shortcuts -y -k --prefix ../env python=3.11.9
source ./conda/bin/activate ../env
./conda/bin/conda install -y pytorch==2.2.1 torchvision==0.17.1 torchaudio==2.2.1 -c pytorch
./conda/bin/conda install -y -c conda-forge faiss-cpu
./conda/bin/conda install -y -c conda-forge "ffmpeg=*=*gpl*"
cd ..
PLATE 4

Fix the standalone requirements for Apple Silicon

nano -w system/requirements/requirements_standalone.txt

In that file, change onnxruntime-gpu>=1.18.1 to onnxruntime>=1.18.1. The GPU build does not apply on this platform. The plain package is the one Plate 6 installs.

PLATE 5

The piper-phonemize wheel

Obtain the wheel file from the piper-phonemize issue linked in the README. Unzip in the alltalk_environment folder and then pip install piper_phonemize-1.1.0-cp311-cp311-macosx_11_0_arm64.whl

Follow the compile steps at the first link instead if you do not trust the wheel file. I kept that choice in the guide on purpose. It is your call.

PLATE 6

Install the requirements and the final upgrades

pip install -r system/requirements/requirements_standalone.txt
pip install --upgrade gradio==4.32.2
pip install -r system/requirements/requirements_parler.txt
./alltalk_environment/conda/bin/conda clean --all --force-pkgs-dirs -y
pip install --upgrade transformers==4.49.0
pip install pip==24.0
pip install git+https://github.com/liyaodev/fairseq.git
PLATE 7

Run

python script.py

Then select XTTS v2 in the app. That last part is an instruction for the app, not part of the command. An earlier version wrote it as one shell line, and a shell cannot parse it that way.

Scope note, in my words

This guide is for an Apple Silicon Mac. You can see it in the file names: the MacOSX-arm64 Miniconda installer and the macosx_11_0_arm64 wheel. The pinned versions above are reproduced exactly as written. They were not re-verified against current releases, because a live install was not attempted in the campaign passes that checked this guide. Treat the pins as a dated snapshot and check the AllTalk project for newer versions before installing.
