AllTalk-V2-MacOS-Guide: The Installation Route

I wrote this guide to get AllTalk v2 running on my Mac. This page walks the same road my README walks: seven stations from Homebrew to a running XTTS v2, every command printed exactly as I gave it, pins and all.

This repo is instructions only. It contains no code of its own, and I want that plain before anything else: what you are following here is my README, set out as a route.

The steps run in order. Each section assumes the ones before it are done, and the working directory matters: I create the environment inside the cloned repo, then step back out of it before the requirements go in. If you stop halfway, the station numbers tell you exactly where you stopped and where to pick the road back up.

The route

Follow the line down. Each station carries its commands exactly as my README gives them, and a short note from me on what the step does and why it sits where it does.

1

Station 1: Homebrew and command line tools

I start here because every later station leans on these tools: ffmpeg and espeak do real work for the voice pipeline, and git is how the project itself arrives at station 2.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew unlink espeak
brew install espeak ffmpeg gcc git curl espeakng
xcode-select --install

The unlink line comes first in my install line on purpose: I clear any older espeak link before Homebrew puts its own in place.

2

Station 2: Clone AllTalk and create the environment folder

I clone the upstream AllTalk project on its alltalkbeta branch, then make the environment folder inside the clone. That folder is home base for the next three stations.

git clone -b alltalkbeta https://github.com/erew123/alltalk_tts
cd alltalk_tts
mkdir alltalk_environment
cd alltalk_environment

Mind the spelling: the folder is alltalk_environment. An earlier pass of my guide had that name mistyped in a later step, and I fixed it, because a folder created under one name and entered under another ends the trip early.

3

Station 3: Miniconda and the Python environment

This is the heaviest station on the route, and I gave it the widest berth. Miniconda goes in locally, the Python 3.11.9 environment is built next to it, and the PyTorch stack, faiss-cpu, and the gpl build of ffmpeg land here, before I step back out with the last line.

curl -LO https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh
bash Miniconda3-latest-MacOSX-arm64.sh -b -p $PWD/conda
./conda/bin/conda create --no-shortcuts -y -k --prefix ../env python=3.11.9
source ./conda/bin/activate ../env
./conda/bin/conda install -y pytorch==2.2.1 torchvision==0.17.1 torchaudio==2.2.1 -c pytorch
./conda/bin/conda install -y -c conda-forge faiss-cpu
./conda/bin/conda install -y -c conda-forge "ffmpeg=*=*gpl*"
cd ..

The arm64 in the installer name is the whole platform story of this guide in one word. If your Mac is not Apple Silicon, this route is not yours.

4

Station 4: Fix the standalone requirements for Apple Silicon

One file, one line changed. I open the standalone requirements in nano and swap a single package name before anything installs from that file at station 6.

nano -w system/requirements/requirements_standalone.txt

Side note: the onnxruntime swap

In that file, I change the first line below to the second, exactly as my guide states it:

onnxruntime-gpu>=1.18.1
onnxruntime>=1.18.1

The GPU build does not apply on this platform. Apple Silicon is not the hardware that package is built for, so leaving the gpu name in place asks the installer for something this machine cannot use. The plain package is the one station 6 installs.

5

Station 5: The piper-phonemize wheel

This station has no tidy install command in my README, so I printed its text exactly as I wrote it there: where the wheel lives, what to do with it, and what to do instead if you would rather not.

Interesting part: obtain the wheel file from here:
https://github.com/rhasspy/piper-phonemize/issues/14#issuecomment-2094395478
The file itself:
https://github.com/rhasspy/piper-phonemize/files/15210981/piper_phonemize-1.1.0-cp311-cp311-macosx_11_0_arm64.whl.zip

Unzip in the alltalk_environment folder and then pip install
piper_phonemize-1.1.0-cp311-cp311-macosx_11_0_arm64.whl

Follow the compile steps at the first link instead if you do not trust
the wheel file.

Side note: where the wheel comes from, and the trust call

The wheel reaches you through a comment on an issue in the rhasspy/piper-phonemize project, not through a package index. I know what that asks of a reader, so my guide keeps its own fallback in the same breath: follow the compile steps at the first link instead if you do not trust the wheel file. I kept that choice in the guide on purpose. It is your call to make, with both doors open.

6

Station 6: Install the requirements and the final upgrades

With the requirements file corrected at station 4 and the wheel handled at station 5, I install from the requirements files, clear the conda caches, and then pin the last upgrades: Gradio, Transformers, pip itself, and fairseq from its git address.

pip install -r system/requirements/requirements_standalone.txt
pip install --upgrade gradio==4.32.2
pip install -r system/requirements/requirements_parler.txt
./alltalk_environment/conda/bin/conda clean --all --force-pkgs-dirs -y
pip install --upgrade transformers==4.49.0
pip install pip==24.0
pip install git+https://github.com/liyaodev/fairseq.git

The order here is mine and it matters to me: the pinned upgrades come after the requirements files, so the versions I chose are the versions left standing.

7

Station 7: Run

The shortest station on the route, and the one the other six exist for.

python script.py

Then select XTTS v2 in the app. That last part is an instruction for the app, not part of the command. An earlier version of my guide wrote it as one shell line with a parenthetical a shell cannot parse, and I fixed that too: the command ends where the command ends.

Honest limits, in my own words

The pinned versions on this page are my guide's dated snapshot, reproduced exactly as written. They were not re-verified against current releases: no live install was attempted for this page, and the upstream sites sit outside the allowed hosts for the pass that built it.

Treat the pins as dated. Check the AllTalk project for newer versions before you install, and expect that some of these numbers will have moved on since I wrote them down.

This route is for an Apple Silicon Mac only. You can see it in the file names I rely on: the MacOSX-arm64 Miniconda installer and the macosx_11_0_arm64 wheel.
